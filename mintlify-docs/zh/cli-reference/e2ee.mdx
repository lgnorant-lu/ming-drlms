## 概述

`e2ee` 命令组用于管理 MP2 模式下的端到端加密密钥。需要连接 MP2 服务器。

```bash
ming-drlms e2ee --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `generate-keys` | 为用户生成端到端密钥 |
| `prekey-bundle` | 获取用户的预密钥包 |

---

## e2ee generate-keys

为指定用户生成 Signal 协议密钥。

### 语法

```bash
ming-drlms e2ee generate-keys [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--user` | `-u` | 必需 | 认证用户名 |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `8080` | 服务器端口 |
| `--target-user` | - | 同 `--user` | 生成密钥的目标用户 |
| `--force` | - | `false` | 强制重新生成 |
| `--token-store` | - | - | 覆盖默认 token 存储路径 |
| `--timeout` | - | `10.0` | 网络超时（秒） |

### 示例

```bash
# 为当前用户生成密钥
ming-drlms e2ee generate-keys -u alice -H 127.0.0.1 -p 15035

# 强制重新生成
ming-drlms e2ee generate-keys -u alice -H 127.0.0.1 -p 15035 --force
```

### 输出示例

```
成功: user=alice code=0 msg='Keys generated' registration_id=12345 pre_keys=100
```

## e2ee prekey-bundle

获取指定用户的预密钥包，用于建立加密会话。

### 语法

```bash
ming-drlms e2ee prekey-bundle [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--user` | `-u` | 必需 | 认证用户名 |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `8080` | 服务器端口 |
| `--target-user` | - | 同 `--user` | 目标用户 |
| `--token-store` | - | - | 覆盖默认 token 存储路径 |
| `--timeout` | - | `10.0` | 网络超时（秒） |

### 示例

```bash
# 获取 bob 的预密钥包
ming-drlms e2ee prekey-bundle -u alice --target-user bob -H 127.0.0.1 -p 15035
```

### 输出示例

```
预密钥包 user=bob device=1 registration=54321
  pre_key_id=1 pre_key_public=abcdef...
  signed_pre_key_id=1 signed_pre_key_public=123456... signed_pre_key_signature=789abc...
  identity_key=def012...
```

## 密钥生命周期

| 密钥类型 | 生成时机 | 有效期 | 用途 |
|----------|----------|--------|------|
| 身份密钥 | 首次调用 | 永久 | 身份标识 |
| 签名预密钥 | 首次/定期 | 周/月 | 会话建立 |
| 一次性预密钥 | 首次/补充 | 单次 | 前向安全 |
