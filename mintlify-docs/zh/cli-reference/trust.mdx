## 概述

`trust` 命令组用于管理联系人的信任状态。DRLMS 实现多级信任模型，从 TOFU（首次信任）到外部锚定验证。

```bash
ming-drlms trust --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `list` | 列出所有联系人信任状态 |
| `show` | 显示联系人详细信任信息 |
| `verify` | 手动验证联系人（指纹比对） |
| `anchor` | 通过外部锚点验证 |
| `accept` | 接受待确认的密钥变更 |
| `revoke` | 撤销联系人信任 |
| `block` | 屏蔽联系人 |
| `unblock` | 解除屏蔽 |

---

## 信任级别

| 级别 | 名称 | 说明 |
|------|------|------|
| -1 | 未知 | 从未交互 |
| 0 | TOFU | 首次信任（Trust On First Use） |
| 1 | 手动验证 | 通过指纹比对确认 |
| 2 | 社交担保 | 由已验证联系人担保 |
| 3 | 外部锚定 | 通过 DNS/HTTPS/GitHub 等验证 |

## trust list

列出所有已知联系人及其信任状态。

### 语法

```bash
ming-drlms trust list [选项]
```

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--all` | `-a` | 显示所有信任级别（包括 UNKNOWN） |
| `--blocked` | `-b` | 包含已屏蔽联系人 |

```
├──────┼─────────────────┼──────────┼────────────────┼────────────┤
│  🟢  │ myuser           │ 手动验证 │ manual: ...    │ 2025-12-11 │
```

### 状态图标

| 图标 | 含义 |

## trust show

### 语法

```bash

```

### 参数

| 参数 | 说明 |
|------|------|
| `公钥或指纹` | 联系人公钥（hex）或指纹前缀 |

### 示例

```bash

ming-drlms trust show 1234
```

## trust verify

手动验证联系人身份（通过指纹比对）。

### 语法

```bash
ming-drlms trust verify <公钥或指纹> [选项]
```

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--fingerprint` | `-f` | 期望的指纹（用于自动比对） |

### 示例

```bash
# 交互式验证（显示指纹供人工比对）
ming-drlms trust verify 0x1234...

# 自动比对验证
ming-drlms trust verify 0x1234... --fingerprint "1234 5678 9ABC DEF0..."
```

### 验证流程

1. 获取对方公钥
2. 通过安全渠道（面对面、电话等）获取对方指纹
3. 运行 `trust verify` 比对
4. 验证成功后，信任级别提升为"手动验证"

## trust anchor

通过外部锚点验证联系人身份。

### 语法

```bash
ming-drlms trust anchor <公钥或指纹> [选项]
```

### 选项

| 选项 | 简写 | 必需 | 说明 |
|------|------|------|------|
| `--type` | `-t` | 是 | 锚定类型: `dns`, `https`, `github` |
| `--id` | `-i` | 是 | 锚定标识: 域名、URL 或 GitHub 用户名 |

### 示例

```bash
# DNS 验证
ming-drlms trust anchor 0x1234... --type dns --id example.com

# HTTPS Well-Known 验证（自动访问 /.well-known/drlms.json）
ming-drlms trust anchor 0x1234... --type https --id example.com

# GitHub 验证
ming-drlms trust anchor 0x1234... --type github --id username
```

## trust revoke

撤销联系人的所有验证，重置为 TOFU。

### 语法

```bash
ming-drlms trust revoke <公钥或指纹>
```

### 说明

此命令将清除联系人的所有验证状态（手动验证、锚定验证等），将其重置为 TOFU（首次信任）状态。

### 示例

```bash
ming-drlms trust revoke 0x1234...
```

## trust accept

接受待确认的密钥变更。

### 语法

```bash
ming-drlms trust accept <公钥或指纹>
```

### 使用场景

当联系人更换设备或重新生成密钥时，DRLMS 会检测到密钥变更并标记为"待确认"。通过安全渠道确认后，使用此命令接受新密钥。

### 示例

```bash
ming-drlms trust accept 0x1234...
```

## 相关概念

### TOFU（Trust On First Use）

首次与某公钥交互时自动信任。这是默认策略，适合大多数场景，但容易受到中间人攻击。

### 密钥变更检测

当检测到联系人公钥变更时：

- `warn`：警告并等待用户确认
- `block`：自动屏蔽直到手动验证
- `reset`：重置为 TOFU 状态

配置方式：

<Tabs>
  <Tab title="Linux/WSL">
    ```bash
    export DRLMS_KEY_CHANGE_ACTION=warn
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    $env:DRLMS_KEY_CHANGE_ACTION = "warn"
    ```
  </Tab>
</Tabs>

### 信任策略

通过 `DRLMS_TRUST_POLICY` 配置默认策略：

| 策略 | 说明 |
|------|------|
| `tofu` | 首次信任（默认） |
| `manual_only` | 仅手动验证 |
| `anchored_only` | 仅外部锚定 |
