## 概述

`client` 命令组提供 MP2 客户端的底层连接和操作功能。

```bash
ming-drlms client --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `list` | 列出服务器文件 |
| `upload` | 上传文件 |
| `download` | 下载文件 |
| `log` | 发送日志消息 |

---

## client list

列出服务器上的文件。

### 语法

```bash
ming-drlms client list [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `15035` | 服务器端口 |
| `--user` | `-u` | `alice` | 用户名 |
| `--password` | `-P` | `password` | 密码 |

### 示例

```bash
ming-drlms client list -H 127.0.0.1 -p 15035 -u alice -P password
```

## client upload

上传文件到服务器。

### 语法

```bash
ming-drlms client upload <文件路径> [选项]
```

### 参数

| 参数 | 说明 |
|------|------|
| `<文件路径>` | 要上传的本地文件 |

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `15035` | 服务器端口 |
| `--user` | `-u` | `alice` | 用户名 |
| `--password` | `-P` | `password` | 密码 |

### 示例

```bash
ming-drlms client upload ~/document.pdf -H 127.0.0.1 -p 15035 -u alice -P password
```

## client download

从服务器下载文件。

### 语法

```bash
ming-drlms client download <远程文件名> [选项]
```

### 参数

| 参数 | 说明 |
|------|------|
| `<远程文件名>` | 服务器上的文件名 |

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--out` | `-o` | 同名 | 输出路径 |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `15035` | 服务器端口 |
| `--user` | `-u` | `alice` | 用户名 |
| `--password` | `-P` | `password` | 密码 |

### 示例

```bash
ming-drlms client download README.md -o ~/downloaded.md -H 127.0.0.1 -p 15035 -u alice -P password
```
