## 概述

`space` 命令组提供房间的加入、离开、发送消息和历史查看功能（基于 Token 缓存）。

```bash
ming-drlms space --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `join` | 加入房间 |
| `leave` | 离开房间 |
| `history` | 查看房间历史 |
| `send` | 发送消息（文本或文件） |
| `chat` | 交互式聊天 |

---

## space join

加入房间并开始接收消息。

### 语法

```bash
ming-drlms space join -r <房间名> [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--room` | `-r` | - | 房间名（必需） |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `8080` | 服务器端口 |
| `--user` | `-u` | `alice` | 用户名 |
| `--password` | `-P` | `password` | 密码 |
| `--since-id` | `-s` | `-1` | 从指定 event_id 开始（-1 使用保存状态） |
| `--save-dir` | `-o` | - | 保存事件的目录 |
| `--json` | `-j` | `false` | JSON 格式输出 |
| `--reconnect` | `-R` | `false` | 自动重连并恢复 |

### 示例

```bash
ming-drlms space join -r general -u alice -P password
ming-drlms space join -r general -u alice -P password --reconnect
```

## space send

发送消息到房间。

### 语法

```bash
ming-drlms space send -r <房间名> [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--room` | `-r` | - | 房间名（必需） |
| `--text` | `-t` | - | 文本内容（与 --file 互斥） |
| `--file` | `-f` | - | 文件路径（与 --text 互斥） |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `8080` | 服务器端口 |
| `--user` | `-u` | `alice` | 用户名 |
| `--password` | `-P` | `password` | 密码 |

### 示例

```bash
# 发送文本
ming-drlms space send -r general -t "Hello!" -u alice -P password

# 发送文件
ming-drlms space send -r general -f /path/to/file.pdf -u alice -P password
```
