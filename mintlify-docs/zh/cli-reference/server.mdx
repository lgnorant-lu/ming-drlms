## 概述

`server` 命令组用于管理 DRLMS C 服务器的启动、停止和状态查询。

```bash
ming-drlms server --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `up` | 启动服务器 |
| `down` | 停止服务器 |
| `status` | 查询服务器状态 |
| `logs` | 查看服务器日志 |

---

## server up

启动 DRLMS C 服务器。

### 语法

```bash
ming-drlms server up [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--port` | `-p` | `8080` | 监听端口 |
| `--data-dir` | `-d` | `server_files` | 数据目录 |
| `--strict/--no-strict` | `-S` | `true` | 严格认证模式 |
| `--max-conn` | `-m` | `128` | 最大连接数 |
| `--config` | `-c` | - | 配置文件路径 |
| `--verbose` | `-v` | `false` | 显示服务器输出 |

### 示例

```bash
# 基本启动（默认端口 8080）
ming-drlms server up -d server_files

# 指定端口
ming-drlms server up --port 15034 -d server_files

# 宽松认证模式
ming-drlms server up --no-strict -d server_files
```

### 别名

```bash
ming-drlms server-up  # 等同于 ming-drlms server up
```

---

## server down

停止运行中的服务器。

### 语法

```bash
ming-drlms server down [选项]
```

<Note>
`server down` 命令无额外选项，直接终止 PID 文件中记录的进程。
</Note>

### 示例

```bash
# 停止服务器
ming-drlms server down
```

### 别名

```bash
ming-drlms server-down  # 等同于 ming-drlms server down
```

## 服务器配置

### 环境变量

| 变量 | 说明 |
|------|------|
| `DRLMS_PORT` | 监听端口 |
| `DRLMS_MAX_CONN` | 最大连接数 |
| `DRLMS_AUTH_STRICT` | 严格认证模式 |
| `DRLMS_JWT_SECRET` | JWT 签名密钥 |
| `DRLMS_ENABLE_MPROTO_V2` | 启用 MP2 协议 |

### 安全配置

生产环境必须配置：

<Tabs>
  <Tab title="Linux/WSL">
    ```bash
    # 生成随机 JWT 密钥
    export DRLMS_JWT_SECRET=$(openssl rand -hex 32)
    
    # 启用严格认证
    export DRLMS_AUTH_STRICT=1
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    # 生成随机 JWT 密钥
    $env:DRLMS_JWT_SECRET = -join ((48..57) + (97..102) | Get-Random -Count 64 | ForEach-Object {[char]$_})
    
    # 启用严格认证
    $env:DRLMS_AUTH_STRICT = "1"
    ```
  </Tab>
</Tabs>

## 故障排查

### 端口被占用

```
port 8080 is already in use; aborting start
```

解决：

```bash
# 查找占用进程
netstat -ano | findstr :8080  # Windows
lsof -i :8080                 # Linux/macOS

# 更换端口
ming-drlms server up --port 15034
```

### 权限不足

```
错误: 无法绑定到端口 (权限不足)
```

解决：

- Linux: 使用 1024 以上端口，或以 root 运行
- Windows: 以管理员身份运行
