## 概述

`config` 命令组用于查看和修改 DRLMS 配置。

```bash
ming-drlms config --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `get` | **获取配置项的值** |
| `set` | **设置配置项的值** |
| `list` | **列出所有配置项** |
| `path` | **显示配置文件路径** |
| `reset` | **重置配置项为默认值** |
| `init` | 初始化配置模板 (drlms.yaml) |
| `init-tui` | 初始化 TUI 配置 (config.toml) |
| `init-cli` | 初始化 CLI 配置 (drlms.yaml) |
| `show` | 显示配置（原始/生效） |
| `validate` | 验证配置最低要求 |
| `apply-cli` | 应用本地配置到用户目录 |
| `apply-tui` | 应用本地 TUI 配置到用户目录 |

## config get

获取配置项的值。

### 语法

```bash
ming-drlms config get <配置键> [--effective | --file-only]
```

### 参数

| 参数 | 说明 |
|------|------|
| `<配置键>` | 配置键路径，如 `backend.mode`、`backend.relay.urls` |
| `--effective` | 显示生效值（含环境变量覆盖，默认） |
| `--file-only` | 仅显示配置文件中的值 |

### 示例

```bash
# 获取后端模式
ming-drlms config get backend.mode

# 获取 Relay 服务器地址
ming-drlms config get backend.relay.urls

# 获取信任策略
ming-drlms config get trust.default_policy

# 获取日志级别
ming-drlms config get logging.level
```

---

## config set

设置配置项的值并保存到 config.toml。

### 语法

```bash
ming-drlms config set <配置键> <值>
```

### 示例

```bash
# 设置后端模式为 Relay
ming-drlms config set backend.mode relay

# 设置 Relay 服务器地址（多个用逗号分隔）
ming-drlms config set backend.relay.urls "http://relay1.com,http://relay2.com"

# 设置用户名
ming-drlms config set identity.user alice

# 设置信任策略
ming-drlms config set trust.default_policy tofu

# 设置日志级别
ming-drlms config set logging.level DEBUG
```

<Note>值会自动解析类型：`true/false` → 布尔，纯数字 → 整数/浮点，逗号分隔 → 列表。</Note>

## config list

列出所有配置项及其当前值。

### 语法

```bash
ming-drlms config list [--section <分区>] [-v]
```

### 选项

| 选项 | 说明 |
|------|------|
| `--section <分区>` | 仅显示指定分区 (general, backend, identity, trust, logging) |
| `-v, --verbose` | 显示详细信息（包括类型） |

### 示例

```bash
# 列出所有配置
ming-drlms config list

# 仅列出后端配置
ming-drlms config list --section backend

# 详细模式
ming-drlms config list -v
```

## config reset

重置配置项为默认值。

### 语法

```bash
ming-drlms config reset [<配置键>] [--yes]
```

### 参数

| 参数 | 说明 |
|------|------|
| `<配置键>` | 要重置的配置键（留空重置所有） |
| `--yes, -y` | 跳过确认 |

### 示例

```bash
# 重置单个配置项
ming-drlms config reset backend.mode

# 重置所有配置（需确认）
ming-drlms config reset

# 重置所有配置（跳过确认）
ming-drlms config reset --yes
```

## config init-tui

初始化 TUI 配置文件 (config.toml)。

### 语法

```bash
ming-drlms config init-tui [--target <位置>]
```

### 位置选项

| 值 | 说明 |
|------|------|
| `local` | 本地仓库 .drlms/config.toml |
| `home` | 用户配置目录 |
| `both` | 两者都创建（默认） |

## config show

显示配置内容。

### 语法

```bash
ming-drlms config show [--effective | --raw]
```

### 选项

| 选项 | 默认 | 说明 |
|------|------|------|
| `--effective` | - | 显示生效配置（合并环境变量覆盖） |
| `--raw` | ✓ | 显示原始配置文件 |


## config apply-cli

将本地配置 (.drlms/drlms.yaml) 应用到用户目录 (~/.drlms/drlms.yaml)。

### 语法

```bash
ming-drlms config apply-cli [--overwrite | --no-overwrite]
```

### 选项

| 选项 | 默认 | 说明 |
|------|------|------|
| `--overwrite` | - | 覆盖已有的用户配置 |
| `--no-overwrite` | ✓ | 不覆盖已有配置（存在时报错） |

<Note>如果目标文件已存在且未指定 `--overwrite`，命令将失败。</Note>
