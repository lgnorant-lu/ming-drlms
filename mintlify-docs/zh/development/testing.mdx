## 运行测试

### 运行所有测试

```bash
pytest
```

### 运行特定目录

```bash
# Python 测试
pytest tests/python/

# 特定模块测试
pytest tests/python/test_relay_*.py
```

### 运行特定文件

```bash
pytest tests/python/test_relay_merkle.py
```

### 运行特定测试

```bash
pytest tests/python/test_relay_merkle.py::test_merkle_proof -v
```

### 带详细输出

```bash
pytest -v --tb=short
```

## Fixtures

### 内置 Fixtures

`tests/python/conftest.py` 提供基本的路径设置：

```python
# conftest.py

@pytest.fixture(autouse=True)
def ensure_pythonpath():
    """确保 src 目录在 sys.path 中"""
    root = Path(__file__).resolve().parents[2]
    src_dir = root / "src"
    if str(src_dir) not in sys.path:
        sys.path.insert(0, str(src_dir))
    yield
```

### 常用 Fixture 模式

```python
# 临时目录（pytest 内置）
def test_with_temp(tmp_path):
    config_file = tmp_path / "config.toml"
    ...

# 模拟 HTTP 请求
import responses

@responses.activate
def test_fetch_events():
    responses.add(
        responses.GET,
        "http://localhost:15019/health",
        json={"status": "ok"},
    )
    ...

# 环境变量
def test_with_env(monkeypatch):
    monkeypatch.setenv("DRLMS_BACKEND_MODE", "relay")
    ...
```

## 测试标记

### 使用 pytest marks

```python
import pytest

@pytest.mark.integration
def test_relay_connection():
    """集成测试（需要外部服务器）"""
    ...

@pytest.mark.skipif(sys.platform == "win32", reason="Unix only")
def test_unix_socket():
    ...
```

### 已定义的标记

项目在 `pyproject.toml` 中定义了以下标记：

| 标记 | 说明 |
|------|------|
| `integration` | 需要外部服务器二进制的测试 |

### 运行特定标记

```bash
# 仅运行集成测试
pytest -m integration

# 跳过集成测试
pytest -m "not integration"
```

## 环境变量速查

测试时常用的环境变量：

| 变量 | 用途 | 测试常用值 |
|------|------|------------|
| `DRLMS_BACKEND_MODE` | 后端类型 | `mp2` 或 `relay` |
| `DRLMS_MP2_HOST` | MP2 服务器地址 | `127.0.0.1` |
| `DRLMS_MP2_PORT` | MP2 服务器端口 | `15035` |
| `DRLMS_DEFAULT_RELAYS` | Relay 服务地址 | `http://127.0.0.1:15019` |
| `DRLMS_LOG_LEVEL` | 日志级别 | `DEBUG` |
| `DRLMS_UPDATE_CHECK` | 更新检查 | `0`（测试时关闭） |
| `MING_DRLMS_CONFIG_DIR` | 配置目录 | `$(pwd)/.drlms` |
| `DRLMS_USER` | 当前用户名 | `alice` |

设置示例：

<Tabs>
  <Tab title="Linux/WSL">
    ```bash
    export DRLMS_BACKEND_MODE=relay
    export DRLMS_DEFAULT_RELAYS=http://127.0.0.1:15019
    export DRLMS_LOG_LEVEL=DEBUG
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    $env:DRLMS_BACKEND_MODE = "relay"
    $env:DRLMS_DEFAULT_RELAYS = "http://127.0.0.1:15019"
    $env:DRLMS_LOG_LEVEL = "DEBUG"
    ```
  </Tab>
</Tabs>
