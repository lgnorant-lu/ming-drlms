## 概述

DRLMS 使用环境变量进行配置。复制 `.env.example` 为 `.env.local` 并按需修改。

```bash
# 加载环境变量（Linux/WSL）
export $(grep -v '^#' .env.local | xargs)

# 加载环境变量（PowerShell）
Get-Content .env.local | ForEach-Object { 
  if ($_ -match '^([^#=]+)=(.*)$') { 
    [System.Environment]::SetEnvironmentVariable($matches[1].Trim(), $matches[2].Trim()) 
  } 
}
```

## 配置路径与目录

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `MING_DRLMS_CONFIG_DIR` | Windows: `%APPDATA%\DRLMS`, Linux: `~/.config/drlms` | 配置目录 |
| `DRLMS_CONFIG_FILE` | - | 配置文件完整路径（优先级高于目录） |
| `DRLMS_DATA_DIR` | Windows: `%LOCALAPPDATA%\drlms`, Linux: `~/.local/share/drlms` | 数据目录 |
| `DRLMS_ROOT` | - | 项目根目录覆盖 |

## 后端模式选择

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DRLMS_BACKEND_MODE` | `relay` | 后端类型：`mp2`（传统）/ `relay`（去中心化）/ `hybrid`（混合） |
| `DRLMS_BACKEND` | - | [兼容] 旧版变量，优先读取 `DRLMS_BACKEND_MODE` |

### MP2 服务器配置

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DRLMS_MP2_HOST` | `127.0.0.1` | MP2 服务器地址 |
| `DRLMS_MP2_PORT` | `15035` | MP2 服务器端口 |
| `DRLMS_MP2_TLS` | `0` | 是否启用 TLS（0/1） |

### Relay 服务器配置

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DRLMS_DEFAULT_RELAYS` | - | Relay 服务器列表（逗号分隔） |
| `DRLMS_RELAY_BASE_URL` | - | [兼容] 旧版单 Relay 变量 |
| `DRLMS_RELAY_ID` | `relay-default` | Relay 身份标识 |
| `DRLMS_RELAYS_CONFIG` | - | Relay 配置文件路径 |

## 日志配置

| 变量 | 默认值 | 说明 |
|------|--------|------|

| `DRLMS_LOG_ROTATE` | `size` | 轮转模式：`size`（按大小）/`time`（按时间） |
| `DRLMS_LOG_KEEP` | `5` | 保留日志文件数量 |
| `DRLMS_LOG_MAX_MB` | `10` | 单文件最大大小（MB） |
| `DRLMS_LOG_CONSOLE` | `1` | 控制台输出（0/1） |
| `DRLMS_LOG_JSON` | `0` | JSON 格式日志（0/1） |

## Relay 服务端配置

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DRLMS_DB_PATH` | `drlms.db` | SQLite 数据库路径 |
| `DRLMS_FILES_DIR` | `relay_files` | 文件存储目录 |
| `DRLMS_RELAY_SIGNING_PRIVKEY` | - | XEdDSA 签名私钥（32字节 hex，64字符） |

生成私钥：
```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

## 示例配置

### Relay 模式（推荐）

```bash
# .env.local
DRLMS_BACKEND_MODE=relay
DRLMS_DEFAULT_RELAYS=http://localhost:15019
DRLMS_USER=alice
DRLMS_TRUST_POLICY=tofu
DRLMS_LOG_LEVEL=INFO
```

### MP2 开发模式

```bash
# .env.local
DRLMS_BACKEND_MODE=mp2
DRLMS_MP2_HOST=127.0.0.1
DRLMS_MP2_PORT=15035
DRLMS_LOG_LEVEL=DEBUG
DRLMS_LOG_CONSOLE=1
```

### Relay 服务端

```bash
# .env.relay
DRLMS_DB_PATH=/var/lib/drlms/drlms.db
DRLMS_FILES_DIR=/var/lib/drlms/files
DRLMS_RELAY_SIGNING_PRIVKEY=<your-64-char-hex-key>
DRLMS_RELAY_ID=relay-prod-01
```
