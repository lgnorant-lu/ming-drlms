## 概述

本页面列出 DRLMS TUI 的所有快捷键绑定。

---

## 全局快捷键

在任何界面都可使用（定义于 `app.py`）：

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+C` | 退出 | 立即退出 TUI |
| `Ctrl+Q` | 退出 | 立即退出 TUI |
| `Ctrl+L` | 日志 | 打开日志查看界面 |
| `F1` | 日志 | 打开日志查看界面（备用） |
| `Ctrl+,` | 设置 | 打开设置界面 |
| `F2` | 设置 | 打开设置界面（备用） |
| `F3` | 配置 | 服务器配置（MP2）或 Relay 配置信息 |

<Note>
`Escape` 键行为由各子界面单独定义，用于关闭当前对话框或返回上级。
</Note>

## 聊天界面

### 消息操作

定义于 `chat_screen.py`：

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Enter` | 发送 | 发送当前输入框的消息 |
| `Ctrl+H` | 帮助 | 显示命令帮助 |
| `Ctrl+E` | E2EE | 显示端到端加密信息 |
| `Ctrl+U` | 上传 | 打开文件选择器上传文件 |
| `Ctrl+R` | 重试 | 重试连接服务器 |
| `Ctrl+B` | 返回 | 返回登录界面 |

### 导航

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Tab` | 切换焦点 | 在房间列表、消息区、输入框间切换 |
| `Shift+Tab` | 反向切换 | 反向切换焦点 |
| `上箭头` | 滚动/历史 | 向上滚动消息或调用命令历史 |
| `下箭头` | 滚动/历史 | 向下滚动消息或调用命令历史 |
| `Page Up` | 翻页 | 向上翻页 |
| `Page Down` | 翻页 | 向下翻页 |
| `Home` | 顶部 | 滚动到最早消息 |
| `End` | 底部 | 滚动到最新消息 |

### 房间操作

<Note>
房间创建/加入通过 `/` 命令实现（如 `/help` 查看可用命令），而非快捷键。
</Note>

## 文件选择器

定义于 `file_selector.py`：

| 快捷键 | 功能 | 说明 |
|--------|------|------|

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Escape` | 关闭 | 返回上级界面 |
| `c` | 清除 | 清除当前日志显示 |
| `s` | 保存 | 保存日志到带时间戳的文件 |

## Relay 启动界面

定义于 `relay_start_screen.py`：

<Note>
Relay 启动界面没有定义专属快捷键，通过按钮交互（进入、创建身份、导入、设置）。

## 快捷键冲突

某些终端可能会拦截特定快捷键。常见冲突：

| 快捷键 | 可能冲突 | 替代方案 |
|--------|----------|----------|
| `Ctrl+C` | 终端中断信号 | 使用 `Ctrl+Q` |
| `Ctrl+L` | 终端清屏 | 使用 `F1` |
| `Ctrl+,` | 某些终端设置 | 使用 `F2` |

### 解决方案

1. **Windows Terminal**: 在设置中禁用冲突的快捷键
2. **iTerm2**: 在 Keys 设置中调整
3. **GNOME Terminal**: 在首选项中修改
