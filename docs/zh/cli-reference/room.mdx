## 概述

`room` 命令组用于管理 MP2 服务器上的房间。需要先登录服务器。

```bash
ming-drlms room --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `create` | 创建新房间 |
| `sub` (或 `join`) | 订阅房间（加入并接收消息） |
| `pub` | 发布消息到房间 |
| `info` | 显示房间信息 |
| `members` | 查看房间成员列表 |
| `set-policy` | 设置房间策略 |
| `set-storage-policy` | 设置存储策略 |
| `transfer` | 转让房间所有权 |
| `clear-owner` | 清空房间所有者 |
| `download` | 下载房间文件 |
| `local-history` | 显示本地历史消息 |

## room create

创建新房间，可指定阅后即焚模式。

### 语法

```bash
ming-drlms room create -r <房间名> [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--room` | `-r` | - | 房间名称（必需） |
| `--ephemeral/--persistent` | - | `persistent` | 存储策略 |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `15035` | 服务器端口 |
| `--user` | `-u` | `myuser` | 用户名 |
| `--token-store` | `-t` | - | Token 存储路径 |

### 示例

```bash
ming-drlms room create -r general
ming-drlms room create -r secret --ephemeral
```

## room sub

订阅房间，加入并接收消息。

<Note>
别名: `join`。例如 `ming-drlms room join -r myroom` 等同于 `ming-drlms room sub -r myroom`。
</Note>

### 语法

```bash
ming-drlms room sub -r <房间名> [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--room` | `-r` | - | 房间名称（必需） |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `15035` | 服务器端口 |
| `--user` | `-u` | `myuser` | 用户名 |
| `--since-id` | `-s` | `0` | 从指定 event_id 开始 |
| `--limit` | `-n` | `0` | 最多接收事件数量（0 不限） |
| `--json` | `-j` | `false` | 以 JSON 输出事件 |
| `--token-store` | - | - | Token 存储路径 |
| `--timeout` | - | `10.0` | Socket 超时时间 |
| `--key-store` | - | - | E2EE 密钥存储路径 |

### 示例

```bash
# 订阅并接收所有消息
ming-drlms room sub -r general

# 从指定事件开始
ming-drlms room sub -r general --since-id 100

# JSON 输出
ming-drlms room sub -r general --json
```

## room pub

发布消息到房间。

### 语法

```bash
ming-drlms room pub -r <房间名> [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--room` | `-r` | - | 目标房间（必需） |
| `--text` | `-t` | - | 文本内容（与 --file/--stdin 互斥） |
| `--file` | `-f` | - | 文件路径（与 --text/--stdin 互斥） |
| `--stdin` | - | `false` | 从标准输入读取（与 --text/--file 互斥） |
| `--ephemeral/--persistent` | - | `persistent` | 事件存储策略 |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `15035` | 服务器端口 |
| `--user` | `-u` | `myuser` | 用户名 |
| `--token-store` | - | - | Token 存储路径 |
| `--timeout` | - | `10.0` | Socket 超时时间 |
| `--key-store` | - | - | E2EE 密钥存储路径 |

### 示例

```bash
# 发送文本
ming-drlms room pub -r general -t "Hello, world!"

# 发送文件
ming-drlms room pub -r general -f /path/to/file.pdf

# 从标准输入发送
echo "Hello" | ming-drlms room pub -r general --stdin

# 阅后即焚消息
ming-drlms room pub -r general -t "Secret" --ephemeral
```

## room set-policy

设置房间实例策略。

### 语法

```bash
ming-drlms room set-policy -r <房间名> --policy <策略> [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--room` | `-r` | - | 房间名（必需） |
| `--policy` | - | - | 策略名（必需） |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `15035` | 服务器端口 |
| `--user` | `-u` | `myuser` | 用户名 |
| `--token-store` | `-t` | - | Token 存储路径 |

### 策略选项

| 策略 | 说明 |
|------|------|
| `retain` | 保留实例 |
| `delegate` | 委托模式 |
| `teardown` | 断开后销毁 |

## room clear-owner

清空房间所有者，使房间回归系统所有。

### 语法

```bash
ming-drlms room clear-owner -r <房间名> -u <用户名> [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--room` | `-r` | - | 房间名（必需） |
| `--user` | `-u` | - | 执行者用户名（必需） |
| `--host` | `-H` | `127.0.0.1` | 服务器地址 |
| `--port` | `-p` | `15035` | 服务器端口 |
| `--token-store` | `-t` | - | Token 存储路径 |

<Note>
清空后房间将采用 delegate 策略，自动将所有权委托给活跃用户。
</Note>
