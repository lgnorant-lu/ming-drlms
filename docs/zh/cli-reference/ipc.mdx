## 概述

`ipc` 命令组是一个**独立的实验性项目**，提供基于共享内存的进程间通信（IPC）功能。

> **注意**: IPC 是独立于 DRLMS 网络协议（Relay/MP2/Legacy）的本地进程间通信实现，主要用于教学和实验目的。

### 特点

- **共享内存通信**：使用操作系统共享内存机制
- **信号量同步**：empty/full 信号量控制读写，防止竞态条件
- **环形缓冲区**：支持多条消息排队
- **跨平台**：支持 Windows 和 Linux
- **文件支持**：可以发送文本消息或文件内容

```bash
ming-drlms ipc --help
```

## 架构说明

### 核心组件

| 组件 | 说明 |
|------|------|
| **共享内存** | 进程间共享的消息缓冲区 |
| **信号量** | 同步机制（empty/full） |
| **环形缓冲区** | 2个槽位，支持消息排队 |
| **C 底层工具** | `log_consumer`（监听）、`ipc_sender`（发送） |

### 工作原理

```
进程 A (Sender)          共享内存           进程 B (Listener)
      |                     |                      |
      | ──── write ───> [Buffer] ───── read ──> |
      |                [Slot 0]                   |
      |                [Slot 1]                   |
      |                     |                      |
   sem_empty <──> Semaphores <──> sem_full
```

## ipc send

发送消息到共享内存缓冲区。

### 语法

```bash
ming-drlms ipc send [选项]
```

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--message` | `-m` | 消息内容（字符串） |
| `--file` | `-f` | 文件路径（读取文件内容作为消息） |
| `--key` | `-k` | 共享内存密钥（十六进制，如 `0x1234`） |
| `--chunk` | - | 分块大小（字节，0=自动） |

### 示例

**发送文本消息**：
```bash
ming-drlms ipc send --key 0x1234 --message "Hello IPC!"
```

**发送文件内容**：
```bash
ming-drlms ipc send --key 0x1234 --file message.txt
```

**使用环境变量**：
```bash
export DRLMS_SHM_KEY=0x1234
ming-drlms ipc send --message "Test"
```

## 完整示例

### 基本消息传递

**终端1 - 启动监听**：
```bash
ming-drlms ipc listen --key 0x1234
```

**终端2 - 发送消息**：
```bash
ming-drlms ipc send --key 0x1234 --message "Message 1"
ming-drlms ipc send --key 0x1234 --message "Message 2"
```

**终端1 输出**：
```
Message 1
Message 2
```

### 文件传输

**创建测试文件**：
```bash
echo "Line 1" > test.txt
echo "Line 2" >> test.txt
```

**发送文件**：
```bash
ming-drlms ipc send --key 0x1234 --file test.txt
```

**监听端接收**：
```
Line 1
Line 2
```

## ipc file-send

发送文件（含完整元信息）到共享内存。**适用于实验五**。

### 语法

```bash
ming-drlms ipc file-send <FILE> [选项]
```

### 参数

| 参数 | 说明 |
|------|------|
| `FILE` | 要发送的文件路径 |

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--key` | `-k` | 共享内存密钥（十六进制） |

### 元信息包含

- 文件名 (filename)
- 文件大小 (filesize)
- 修改时间 (modified_time)
- 发送者 (sender PID)
- 序列号 (sequence)
- 魔数验证 (0x4D455441)

### 示例

**发送文本文件**：
```bash
ming-drlms ipc file-send test.txt
```

**发送大文件**：
```bash
ming-drlms ipc file-send large_data.bin --key 0x5678
```

**预期输出**：
```
[META] 发送文件元信息:
  文件名: test.txt
  大小: 2048 字节
  发送者: pid_12345
[DATA] 发送文件内容...
  进度: 2048 / 2048 字节 (100.0%)
[DONE] 文件传输完成: 2048 字节
```

## ipc file-receive

接收文件（自动解析元信息）从共享内存。**适用于实验五**。

### 语法

```bash
ming-drlms ipc file-receive [选项]
```

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--output` | `-o` | 输出目录（默认: ./received/） |
| `--key` | `-k` | 共享内存密钥（十六进制） |

### 示例

**接收到默认目录**：
```bash
ming-drlms ipc file-receive
```

**指定输出目录**：
```bash
ming-drlms ipc file-receive --output ./downloads/
```

**预期输出**：
```
=== 文件元信息 ===
  文件名: test.txt
  大小: 2048 字节 (2.00 KB)
  发送者: pid_12345
  修改时间: 2025-12-15 10:30:00
==================

[接收] 正在接收文件内容...
  进度: 2048 / 2048 字节 (100.0%)
[SUCCESS] 文件接收完成: ./received/test.txt (2048 字节)
```

## 技术细节

### 共享内存配置

| 参数 | 值 |
|------|-----|
| 缓冲区大小 | 16384 字节 |
| 槽位大小 | 4096 字节 |
| 槽位数量 | 2 个 |
| 信号量 | 2 个（empty, full） |

### Windows 实现

- **共享内存**: `CreateFileMapping` / `MapViewOfFile`
- **信号量**: Named Semaphores (`CreateSemaphoreW`)
- **信号量名称格式**: `Local\drlms_shm_sem_<key>_empty|full`

### Linux 实现

- **共享内存**: POSIX `shm_open` / `mmap`
- **信号量**: POSIX Named Semaphores

## 实验用途

IPC 功能主要用于以下场景：

1. **进程间通信实验**：学习共享内存和信号量机制
2. **本地消息传递**：无需网络的进程间数据交换
3. **性能测试**：测试高频消息传递性能
4. **教学演示**：演示 IPC 的工作原理

> **不适用于**：生产环境、跨网络通信、持久化存储

## 故障排除

### 常见问题

**Q: 发送失败，提示 "shm_init failed"**  
A: 确保 `log_consumer` 编译成功并在 `build_win_ninja_x64/` 目录下。

**Q: Listener 没有显示消息**  
A: 检查两个进程使用相同的 `--key` 值。

**Q: Windows 上找不到信号量（error=2）**  
A: 先启动 listener创建共享内存，再启动 sender。

### 清理共享内存

**Linux**：
```bash
# 查看共享内存
ipcs -m
# 删除
ipcrm -M 0x1234
```

**Windows**：
共享内存在最后一个进程退出时自动清理。
