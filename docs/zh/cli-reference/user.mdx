## 概述

`user` 命令组用于管理 MP2 服务器上的用户账户。

```bash
ming-drlms user --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `list` | 列出用户 |
| `add` | 添加用户 |
| `del` | 删除用户 |
| `passwd` | 修改密码 |

---

## user list

列出服务器上的用户。

### 语法

```bash
ming-drlms user list [选项]
```

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--data-dir` | `-d` | 数据目录 |
| `--config` | `-c` | 配置文件 |
| `--json` | `-j` | JSON 格式输出 |

### 示例

```bash
ming-drlms user list
ming-drlms user list --json
```

---

## user add

添加新用户（密码使用 Argon2id 哈希）。

### 语法

```bash
ming-drlms user add <用户名> [选项]
```

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--data-dir` | `-d` | 数据目录 |
| `--config` | `-c` | 配置文件 |
| `--password-from-stdin` | `-x` | 从 stdin 读取密码（否则交互式输入） |

### 示例

```bash
# 交互式输入密码
ming-drlms user add peer

# 从 stdin 读取
echo 'secret123' | ming-drlms user add peer -x
```

## user passwd

修改用户密码。

### 语法

```bash
ming-drlms user passwd <用户名> [选项]
```

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--data-dir` | `-d` | 数据目录 |
| `--config` | `-c` | 配置文件 |
| `--password-from-stdin` | `-x` | 从 stdin 读取密码 |

### 示例

```bash
ming-drlms user passwd myuser
# 交互式输入新密码

# 从 stdin 读取
echo 'newsecret' | ming-drlms user passwd myuser -x
```

---

## user del

删除用户。

### 语法

```bash
ming-drlms user del <用户名> [选项]
```

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--data-dir` | `-d` | 数据目录 |
| `--config` | `-c` | 配置文件 |
| `--force` | `-f` | 用户不存在时不报错 |

### 示例

```bash
ming-drlms user del peer
ming-drlms user del peer --force
```
