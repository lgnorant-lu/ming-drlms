## 概述

`relay` 命令组提供 Relay 服务器的底层操作，用于调试和高级用途。

```bash
ming-drlms relay --help
```

---

## 命令列表

| 命令 | 说明 |
|------|------|
| `post-simple` | 发布消息（使用 IdentityManager） |
| `post-multi` | 多 Relay 投递 |
| `sync-multi` | 多 Relay 同步 |
| `identity` | 管理 Relay 身份 |

---

## relay post-simple

使用 IdentityManager（Phase 15.5 XEdDSA）发布消息到 Relay。

### 语法

```bash
ming-drlms relay post-simple -r <房间> -c <内容> [选项]
```

### 选项

| 选项 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| `--room` | `-r` | - | 目标房间（必需） |
| `--content` | `-c` | - | 消息内容（必需） |
| `--base-url` | - | `http://127.0.0.1:15019` | Relay 服务器 URL |
| `--content-type` | - | `text` | 内容类型 |
| `--user` | `-u` | DRLMS_USER | 用户名 |

### 示例

```bash
ming-drlms relay post-simple -r general -c "Hello!" --user myuser
```

## relay post-multi

向多个 Relay 并行投递事件（需要 relays.toml 配置）。

### 语法

```bash
ming-drlms relay post-multi -r <房间> --ciphertext <密文> --client-hash <哈希> [选项]
```

### 选项

| 选项 | 说明 |
|------|------|
| `--room`, `-r` | 目标房间（必需） |
| `--ciphertext` | Base64 密文（必需） |
| `--client-hash` | 客户端事件哈希（必需） |
| `--content-len` | 内容长度 |
| `--client-ts` | 客户端时间戳 |
| `--config` | relays.toml 路径 |

## relay sync-multi

从多个 Relay 同步房间（使用 MultiRelaySyncManager）。

### 语法

```bash
ming-drlms relay sync-multi -r <房间> [选项]
```

### 选项

| 选项 | 说明 |
|------|------|
| `--room`, `-r` | 房间 ID（必需） |
| `--config` | relays.toml 路径 |

## relay identity

管理 Relay 客户端身份（Phase 15.5 XEdDSA）。

### 语法

```bash
ming-drlms relay identity <action> [选项]
```

### Action 参数

| Action | 说明 |
|--------|------|
| `show` | 显示当前身份（默认） |
| `create` | 创建新的 X25519 身份 |
| `export` | 导出私钥用于备份 |

### 选项

| 选项 | 简写 | 说明 |
|------|------|------|
| `--user` | `-u` | 用户名（或设置 DRLMS_USER） |

### 示例

```bash
# 查看当前身份
ming-drlms relay identity show --user myuser

# 创建新身份
ming-drlms relay identity create --user myuser

# 导出私钥
ming-drlms relay identity export --user myuser
```
