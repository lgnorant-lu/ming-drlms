DRLMS 计划提供 Docker 镜像，方便快速部署 Relay 服务器。

## 快速开始

### 拉取镜像

```bash
docker pull ghcr.io/lgnorant-lu/ming-drlms:latest
```

### 运行 Relay 服务器

```bash
docker run -d \
  --name drlms-relay \
  -p 15019:15019 \
  -v drlms-data:/data \
  -e DRLMS_DB_PATH=/data/relay.db \
  ghcr.io/lgnorant-lu/ming-drlms:latest \
  uvicorn ming_drlms.relay.server:app --host 0.0.0.0 --port 15019
```

## Dockerfile

### Relay 服务器

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# 安装依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制代码
COPY . .
RUN pip install --no-cache-dir .

# 创建数据目录
RUN mkdir -p /data

# 暴露端口
EXPOSE 15019

# 环境变量
ENV DRLMS_DB_PATH=/data/relay.db
ENV DRLMS_FILES_DIR=/data/files

# 启动命令
CMD ["uvicorn", "ming_drlms.relay.server:app", "--host", "0.0.0.0", "--port", "15019"]
```

### 构建镜像

```bash
docker build -t drlms-relay:latest .
```

## Docker Compose

### 单 Relay 部署

```yaml
# docker-compose.yml
version: '3.8'

services:
  relay:
    image: ghcr.io/lgnorant-lu/ming-drlms:latest
    command: uvicorn ming_drlms.relay.server:app --host 0.0.0.0 --port 15019
    ports:
      - "15019:15019"
    volumes:
      - relay-data:/data
    environment:
      - DRLMS_DB_PATH=/data/relay.db
      - DRLMS_FILES_DIR=/data/files
      - DRLMS_RELAY_SIGNING_PRIVKEY=${RELAY_SIGNING_KEY}
    restart: unless-stopped

volumes:
  relay-data:
```

### 多 Relay 联邦

```yaml
# docker-compose.federation.yml
version: '3.8'

services:
  relay1:
    image: ghcr.io/lgnorant-lu/ming-drlms:latest
    command: uvicorn ming_drlms.relay.server:app --host 0.0.0.0 --port 15019
    ports:
      - "15019:15019"
    volumes:
      - relay1-data:/data
    environment:
      - DRLMS_DB_PATH=/data/relay.db
      - DRLMS_FILES_DIR=/data/files

  relay2:
    image: ghcr.io/lgnorant-lu/ming-drlms:latest
    command: uvicorn ming_drlms.relay.server:app --host 0.0.0.0 --port 15019
    ports:
      - "15020:15019"
    volumes:
      - relay2-data:/data
    environment:
      - DRLMS_DB_PATH=/data/relay.db
      - DRLMS_FILES_DIR=/data/files

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    depends_on:
      - relay1
      - relay2

volumes:
  relay1-data:
  relay2-data:
```

## 环境变量

**服务器配置**：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DRLMS_DB_PATH` | `drlms.db` | 数据库路径 |
| `DRLMS_FILES_DIR` | `relay_files` | 文件存储目录 |
| `DRLMS_RELAY_ID` | `relay-default` | Relay 标识 |
| `DRLMS_RELAY_SIGNING_PRIVKEY` | - | XEdDSA 签名私钥 |
| `DRLMS_LOG_LEVEL` | `INFO` | 日志级别 (DEBUG/INFO/WARNING/ERROR) |

## 数据持久化

### 使用 Volume

```bash
docker volume create drlms-data

docker run -d \
  -v drlms-data:/data \
  ghcr.io/lgnorant-lu/ming-drlms:latest
```

### 使用 Bind Mount

```bash
docker run -d \
  -v /opt/drlms/data:/data \
  ghcr.io/lgnorant-lu/ming-drlms:latest
```
