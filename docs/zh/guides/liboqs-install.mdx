## 概述

liboqs 是开源后量子密码学库，为 DRLMS Phase 27 提供 ML-KEM-768 (Kyber768) 支持。

<Note>
如果不安装 liboqs，PQC 功能会自动禁用，系统回退到纯 X25519 加密。
</Note>

---

## 方法 1: vcpkg 构建 (推荐)

项目已在 `vcpkg.json` 中声明 liboqs 依赖。重新配置 CMake 即可自动安装：

<Tabs>
  <Tab title="Windows">
    ```powershell
    # 1. 确保 vcpkg.json 已更新
    
    # 2. 使用 Ninja 重新配置 (推荐, 速度快且已验证)
    # 这会自动下载并编译 liboqs
    cmake --preset windows-ninja
    
    # 3. 构建
    # 注意：build 目录名称取决于 preset 名称 (windows-base 强制为 build_win)
    cmake --build build_win
    
    # 4. 构建完成后，DLL 位于:
    # build_win/vcpkg_installed/x64-windows/bin/oqs.dll
    ```
    
    <Note>
    如果你更喜欢使用 Visual Studio 解决方案，请使用 `windows-vcpkg` 预设，
    但需先清理 `build*` 目录以避免生成器冲突：
    `Remove-Item -Recurse -Force build* -ErrorAction SilentlyContinue`
    `cmake --preset windows-vcpkg`
    </Note>
  </Tab>
  <Tab title="Linux/WSL">
    ```bash
    # 1. 重新配置
    cmake --preset linux-vcpkg
    
    # 2. 构建
    cmake --build build_wsl
    
    # 3. 库位于:
    # build_wsl/vcpkg_installed/x64-linux/lib/liboqs.so
    ```
  </Tab>
</Tabs>

### 配置 Python 环境

<Tabs>
  <Tab title="Windows">
    ```powershell
    # 方法 A: 设置环境变量
    $env:DRLMS_LIBOQS_PATH = "$PWD\build_win_ninja_x64\vcpkg_installed\x64-windows\bin\oqs.dll"
    
    # 方法 B: 添加到 PATH
    $env:PATH = "$PWD\build_win_ninja_x64\vcpkg_installed\x64-windows\bin;$env:PATH"
    
    # 验证
    .\.venv.win\Scripts\Activate.ps1
    python -c "import oqs; print('liboqs OK')"
    ```
  </Tab>
  <Tab title="Linux/WSL">
    ```bash
    # 设置 LD_LIBRARY_PATH
    export LD_LIBRARY_PATH="$PWD/build_wsl/vcpkg_installed/x64-linux/lib:$LD_LIBRARY_PATH"
    
    # 验证
    source .venv/bin/activate
    python -c "import oqs; print('liboqs OK')"
    ```
  </Tab>
</Tabs>

## 方法 2: 项目构建脚本 (推荐)

使用项目提供的自动化脚本构建最新版本 liboqs：

<Tabs>
  <Tab title="Windows">
    ```powershell
    # 1. 在 Developer PowerShell for VS 中运行
    # 或者脚本会自动检测并加载 MSVC 环境

    # 2. 执行构建脚本
    .\scripts\install_liboqs.ps1

    # 3. 构建完成后，设置环境变量
    $env:LIBOQS_DIR = "$PWD\build_win\_deps\liboqs-install"
    $env:PATH += ";$PWD\build_win\_deps\liboqs-install\bin"

    # 4. 验证
    python -c "import oqs; print('liboqs:', oqs.oqs_version())"
    ```
  </Tab>
  <Tab title="Linux/WSL">
    ```bash
    # 手动构建
    git clone --depth 1 https://github.com/open-quantum-safe/liboqs.git
    cd liboqs && mkdir build && cd build
    cmake -DBUILD_SHARED_LIBS=ON ..
    make -j$(nproc)
    sudo make install

    # 验证
    python -c "import oqs; print('liboqs:', oqs.oqs_version())"
    ```
  </Tab>
</Tabs>

<Note>
此方法构建的是 liboqs `main` 分支 (0.15.0-dev)，与 liboqs-python 0.14.1 兼容。
会显示版本不匹配警告，但功能正常。
</Note>

## 方法 3: 手动编译

如需完全控制或不使用 vcpkg：

```powershell
# 1. 克隆
git clone https://github.com/open-quantum-safe/liboqs.git
cd liboqs

# 2. 构建
mkdir build && cd build
cmake -G "Visual Studio 17 2022" -A x64 ..
cmake --build . --config Release

# 3. 安装
cmake --install . --prefix C:\liboqs

# 4. 配置环境
$env:DRLMS_LIBOQS_PATH = "C:\liboqs\bin\oqs.dll"
```

---

## 环境变量

在 `.env.local` 中配置：

```bash
# 启用 PQC (默认开启)
DRLMS_PQC_ENABLED=1

# liboqs 库路径 (可选，如果在 PATH 中可省略)
DRLMS_LIBOQS_PATH=C:\path\to\oqs.dll

# PQC 算法 (默认 ML-KEM-768)
DRLMS_PQC_ALGORITHM=ML-KEM-768
```

## 故障排查

### "No oqs shared libraries found"

1. 检查 DLL 是否存在:
   ```powershell
   Test-Path $env:DRLMS_LIBOQS_PATH
   ```

2. 确保架构匹配 (x64)

3. 安装 Visual C++ Redistributable:
   ```powershell
   winget install Microsoft.VCRedist.2015+.x64
   ```

### liboqs-python 自动下载失败

这是因为 liboqs-python 尝试自动编译本地库但缺少依赖。使用上述 vcpkg 方法安装。
