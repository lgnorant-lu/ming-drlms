## 概述

DRLMS TUI（Terminal User Interface）是基于 Textual 框架构建的终端界面，提供丰富的交互体验。

[IMAGE: TUI 主界面截图 - 显示房间列表、消息区域和状态栏]

---

## 启动 TUI

```bash
ming-drlms tui
```

### 模式配置

TUI 通过环境变量控制后端模式：

```bash
# MP2 模式（默认）
ming-drlms tui

# Relay 模式
DRLMS_BACKEND_MODE=relay ming-drlms tui
```

<Note>
`tui` 命令不接受命令行选项，配置通过环境变量或配置文件控制。
</Note>

## 快捷键总览

### 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+C` / `Ctrl+Q` | 退出 TUI |
| `Ctrl+L` / `F1` | 打开日志查看 |
| `Ctrl+,` / `F2` | 打开设置 |
| `F3` | 服务器配置（MP2）/ Relay 配置 |

### 聊天界面快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+H` | 显示帮助 |
| `Ctrl+E` | 显示 E2EE 信息 |
| `Ctrl+U` | 上传文件 |
| `Enter` | 发送消息 |
| `Tab` | 切换焦点 |
| `上/下箭头` | 滚动消息 |

### 文件选择器快捷键

| 快捷键 | 功能 |
|-----------|------|
| `Enter` | 选择文件并上传 |
| `Escape` | 取消选择 |

<Note>
文件导航使用 Textual DirectoryTree 组件的默认行为。
</Note>

## 主题配置

### 内置主题

| 主题 | 说明 |
|------|------|
| `forest` | 绿色森林风格（默认） |
| `cyberpunk` | 赛博朋克风格 |

### 配置主题

在 `config.toml` 中设置：

```toml
[tui]
theme = "forest"
```

### 自定义颜色

```toml
[tui.custom_colors]
primary = "#5C9E31"
background = "#1d2021"
surface = "#282828"
text = "#ebdbb2"
accent = "#8BC34A"
```

## 房间操作

### 加入房间

1. 在房间列表中使用上/下箭头选择房间
2. 按 `Enter` 加入
3. 或点击房间名称

### 创建房间（MP2 模式）

房间创建通过命令实现：

```bash
# 在输入框中输入命令
/help  # 查看可用命令
```

### 切换房间

- 使用鼠标点击房间列表
- 或使用 `Tab` 切换焦点后用箭头选择

---

## 消息操作

### 发送消息

1. 在输入框中输入消息
2. 按 `Enter` 发送

### 发送文件

1. 按 `Ctrl+U` 打开文件选择器
2. 浏览并选择文件
3. 按 `Enter` 确认上传

### 查看历史

- 使用滚轮或上/下箭头滚动消息区域
- 历史消息自动加载

## E2EE 功能

### 查看 E2EE 状态

按 `Ctrl+E` 显示：

- 当前房间加密状态
- 会话密钥信息
- 参与者公钥指纹

### E2EE 指示器

状态栏显示：

| 图标 | 含义 |
|------|------|
| 锁定图标 | E2EE 已启用 |
| 开锁图标 | E2EE 未启用 |
| 警告图标 | 密钥验证警告 |

## 设置界面

按 `F2` 打开设置：

### 主题设置

- 主题选择（forest/cyberpunk）

### 日志设置

- 日志级别（DEBUG/INFO/WARNING/ERROR/CRITICAL）
- 控制台输出
- 日志轮转模式（size/time）
- 日志保留数量
- 最大日志大小
- JSON 格式输出
- 日志目录

---

## 日志查看

按 `Ctrl+L` 或 `F1` 打开日志界面：

- 实时日志滚动
- 按级别过滤（DEBUG/INFO/WARN/ERROR）
- `c` 键清除日志显示
- `s` 键保存日志到文件

## 故障排查

### 界面显示异常

1. 检查终端尺寸（建议 120x30 以上）
2. 使用支持 Unicode 的字体
3. 设置正确的终端环境

<Tabs>
  <Tab title="Linux/WSL">
    ```bash
    export TERM=xterm-256color
    ```
  </Tab>
  <Tab title="Windows">
    使用 Windows Terminal 即可自动支持。如使用传统 CMD：
    ```powershell
    [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
    ```
  </Tab>
</Tabs>

### 颜色不正确

确保终端支持 256 色或真彩色：

<Tabs>
  <Tab title="Linux/WSL">
    ```bash
    # 检查颜色支持
    echo $COLORTERM
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    # Windows Terminal 默认支持真彩色
    # 检查是否运行在 Windows Terminal 中
    echo $env:WT_SESSION
    ```
  </Tab>
</Tabs>

### 输入延迟

1. 检查网络连接
2. 减少日志级别
3. 禁用不必要的功能

### 快捷键不工作

某些终端可能拦截快捷键。尝试：

1. 使用备用快捷键（如 F1 替代 Ctrl+L）
2. 更换终端模拟器
3. 检查终端快捷键设置
