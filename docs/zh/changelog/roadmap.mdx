## 当前进展（v0.4.0 开发中）

v0.4.0 是一个重大版本，包含 Phase 14-20 的所有工作（约 120+ commits）：

| Phase | 主题 | 状态 |
|-------|------|------|
| Phase 14 | XEdDSA 签名、Relay 文件链路 | ✅ 已完成 |
| Phase 15/15.5 | Signal Protocol、XEdDSA 迁移 | ✅ 已完成 |
| Phase 16 | 多 Relay 联邦架构 | ✅ 已完成 |
| Phase 17 | XEdDSA 非对称签名（移除 HMAC） | ✅ 已完成 |
| Phase 18 | Relay 去中心化核心 | ✅ 已完成 |
| Phase 19 | Relay 模式 CLI/TUI 完整 | ✅ 已完成 |
| Phase 20 | Mintlify 文档站点 | 🔄 进行中 |

## 长期计划（v1.0）

### 功能完善

- **音视频通话**: WebRTC 集成（计划中）
- **文件预览**: 图片/文档内联预览
- **消息搜索**: 本地全文搜索

### 平台扩展

- **移动客户端**: iOS/Android 应用（考虑中）
- **Web 客户端**: 浏览器版本（考虑中）
- **桌面应用**: Electron 封装（考虑中）

### 企业特性

- **审计日志**: 完整操作审计
- **合规支持**: 数据导出/保留策略
- **SSO 集成**: SAML/OIDC 支持
