## v0.4.0（开发中）

<Warning>
此版本尚未正式发布。以下内容来自 Phase 14-20 的开发进度，包含约 120+ 个 commits。
</Warning>

### Phase 20: 文档站点

- **Mintlify 文档**: 双语（中文/英文）完整文档
- **CLI 参考**: 17 个命令组完整参考
- **API 参考**: Relay 服务器 OpenAPI 规范
- **架构文档**: 系统设计详解

### Phase 24-25: Sender Key 分发机制

- **Push 机制 (Phase 24)**: 成员加入时自动推送 Sender Key
- **Pull 机制 (Phase 25)**: 新成员主动请求缺失的 Sender Key
- **协议扩展**: 新增 `MSG_TYPE_E2EE_SENDER_KEY_REQUEST` (505)
- **双向保障**: Push + Pull 确保密钥分发的可靠性
- **测试覆盖**: 29+ 单元测试验证核心逻辑

### Phase 18-19: Relay 去中心化核心

- **本地身份自举**: 完全去中心化身份管理
- **多级信任模型**: TOFU / 手动验证 / 社交担保 / 外部锚定
- **Relay-Native 房间**: 私有、公开、未列出三种可见性
- **CLI 完整 Relay 流程**: identity / trust / chat / relay-room 命令组
- **TUI Relay 模式**: 启动界面、聊天视图、消息同步
- 测试覆盖: 113 个测试

### Phase 17: XEdDSA 非对称签名

- XEdDSA 签名/验证完整实现
- 移除 HMAC 对称签名（Phase 17C）
- 回执签名验证（RCV-01）
- 公钥通过 Well-Known 自动发现

### Phase 16: 多 Relay 联邦

- **多 Relay 发现**: 静态配置 / 缓存 / DNS / Well-Known / Bootstrap 五层发现
- **健康检查**: 综合评分系统（延迟加权 + 失败降级）
- **事件去重**: 滚动窗口 + event_id 完全去重
- **Merkle 一致性**: 增量构建、根交换、证明验证
- **同步协议**: 增量 / Merkle / 完整三种模式
- **离线队列**: SQLite 持久化 + 指数退避重试

### Phase 14-15.5: 基础 E2EE 与 Relay

- **XEdDSA 端到端签名**: C 桥接 + Python 验签
- **Relay 文件事件链路**: 上传/下载/TUI 文件气泡
- **Signal Protocol 集成**: Double Ratchet、X3DH
- **TUI 身份显示**: 身份解析与信任标记

### 新增 CLI 命令

```bash
# 身份管理 [Relay Only]
ming-drlms identity create/show/fingerprint/export/import

# 信任管理 [Relay Only]
ming-drlms trust list/verify/anchor/accept/block

# Relay 房间 [Relay Only]
ming-drlms relay-room create/list/invite/join/leave/discover/info

# Relay 聊天 [Relay Only]
ming-drlms chat send/recv/publish-bundle
```

### 新增环境变量

| 变量 | 说明 |
|------|------|
| `DRLMS_BACKEND_MODE` | 后端模式: mp2 / relay / hybrid |
| `DRLMS_DEFAULT_RELAYS` | Relay 服务器列表 |
| `DRLMS_TRUST_POLICY` | 信任策略: tofu / manual_only / anchored_only |
| `DRLMS_KEY_CHANGE_ACTION` | 密钥变更行为: warn / block / reset |

## v0.3.2 (2025-10-26)

**紧急安全修复与测试架构增强**

<Warning>
🚨 **安全公告**: 严重性高危。强烈建议所有用户立即从 v0.3.1 及更早版本升级至 v0.3.2。
</Warning>

### 安全修复

- **缓冲区污染**: 修复文件上传/下载时缓冲区被上一次传输残留数据覆盖
- **路径遍历**: 新增 `is_safe_path` 函数，封堵任意文件访问漏洞
- **部分写入**: 检查 `fwrite` 返回值，正确处理 I/O 错误

### 测试架构

- 可扩展测试环境管理系统（`test_env_init.sh`, `test_user_mgmt.sh`）
- 修复 `integration_space.sh` 用户认证逻辑
- 修复 Argon2 密码升级测试用户名不匹配问题

### CI/CD

- 修复 `release_gui.yml` 触发条件
- 修复 `make coverage` 路径安全检查导致的 CI 失败

## v0.3.1 (2025-09-24)

**核心功能稳定版**

解决 v0.3.0 全面回归测试中发现的所有阻塞性问题。

### 认证与安全

- 修复 Windows CRLF 换行符导致 `users.txt` 解析失败
- 修复服务器启动时"空缓存"安全漏洞
- `LOG` 命令必须在认证后使用

### 进程间通信 (IPC)

- `sem_wait` 增加 EINTR 信号中断处理
- `log_consumer` 退出时正确调用 `shm_cleanup`

### CLI

- 错误响应正确返回非零退出码

### 服务器

- `PUBT/PUBF` 增加 event_id 校验
